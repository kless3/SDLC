# Гликемический индекс продуктов

Лабораторная работа № 1, вариант 11. Приложение написано на Java 25 с использованием Swing и архитектуры MVC с активной моделью.

## Возможности

- ввод названия продукта в отдельном модальном окне;
- поиск продукта во встроенном справочнике;
- отображение значения и категории гликемического индекса;
- восстановление последнего корректного продукта при повторном вводе;
- проверка пустого, слишком длинного и некорректного ввода;
- автоматическое обновление представления после изменения модели.

Значения ГИ приведены для учебной демонстрации и являются ориентировочными: фактический показатель зависит от сорта продукта, состава и способа приготовления. Программа не является медицинским справочником.

## Запуск в IntelliJ IDEA

1. Открыть папку проекта или файл `pom.xml`.
2. Выбрать JDK 25 в `File -> Project Structure -> Project SDK`.
3. Запустить метод `main` класса `by.bsuir.glycemicindex.App`.

Внешние библиотеки не требуются.

## Источник классификации

Низкий ГИ: до 55 включительно; средний: 56–69; высокий: от 70. Диапазоны и ориентировочные значения основаны на International Tables of Glycemic Index and Glycemic Load Values 2021.
