# ADR-003: Spring Security и разграничение прав

**Статус:** Принято  
**Проект:** FocusFlow, ЛР4

## Контекст
Личные заметки и привычки должны быть закрыты для других; командные ресурсы видны только участникам.

## Рассмотренные варианты
Самописный security-слой; Spring Security со сверкой ownerId/teamId и OWNER/MEMBER.

## Решение
Spring Security, BCrypt cost ≥ 12, защита CSRF и проверки владельца/членства.

## Последствия
Нужны негативные security-тесты (чужой id, чужая команда), ограничение доступа на сервере.

## Проверка и связь с требованиями
Решение должно быть проверено соответствующими системными требованиями из [requirements.md](../requirements.md) и тестами на этапе реализации. Это документация проектного решения, не свидетельство готового кода.
