# ADR-001: Серверный MVC с Spring Boot и Thymeleaf

**Статус:** Принято  
**Проект:** FocusFlow, ЛР4

## Контекст
Для учебной версии важны единый стек, быстрый серверный контроль прав и срок 8 недель.

## Рассмотренные варианты
Отдельное SPA + REST API; серверная MVC с Thymeleaf.

## Решение
Spring Boot/Spring MVC + Thymeleaf как единое развертываемое приложение.

## Последствия
Меньше интеграций и стоимость реализации; богатый клиентский UI требует дополнительных решений.

## Проверка и связь с требованиями
Решение должно быть проверено соответствующими системными требованиями из [requirements.md](../requirements.md) и тестами на этапе реализации. Это документация проектного решения, не свидетельство готового кода.
