# ADR-004: Агрегаты панели из основной БД

**Статус:** Принято  
**Проект:** FocusFlow, ЛР4

## Контекст
Нужны актуальные показатели по целям, привычкам и событиям без дополнительной инфраструктуры.

## Рассмотренные варианты
Отдельный кэш/материализованная витрина; запросы напрямую в PostgreSQL.

## Решение
Прямые запросы в основную БД без кэша для первой версии.

## Последствия
Требуются индексы по owner_id и date и тест отклика ≤ 2 с при 1000 объектах.

## Проверка и связь с требованиями
Решение должно быть проверено соответствующими системными требованиями из [requirements.md](../requirements.md) и тестами на этапе реализации. Это документация проектного решения, не свидетельство готового кода.
