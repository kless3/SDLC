# Реестр рисков итогового плана P2

| Риск | Вероятность / влияние | Реагирование | Ранний сигнал |
|---|---|---|---|
| Дубли отметок привычки при повторном запросе | Средняя / среднее | UNIQUE(habitId,date), транзакция, идемпотентность | Две строки за день |
| Чтение чужих целей или заметок по ID | Низкая / высокое | Проверять ownerId, teamId и membership | 200 вместо 403/404 |
| Панель медленнее 2с при 1000 объектах | Средняя / среднее | Индексы owner_id/date; тест запросов | Отклик > 2с |
| CSV-инъекция при открытии экспорта | Средняя / высокое | Защита формул и корректное CSV-экранирование | Формула исполняется в CSV |
| Junior задерживает интеграцию | Средняя / среднее | Небольшие задачи, шаблоны, ревью | Многократные возвраты |
| Новое требование перед релизом | Средняя / высокое | Change request, переоценка P2 | Неоцененная задача |

По завершении каждой итерации сравнивать фактические и плановые результаты. Сокращение тестирования/контроля доступа не используется как резерв срока.
