# ADR-005: Безопасный CSV-экспорт после CHG-002

**Статус:** Учебно принято  
**Проект:** FocusFlow, ЛР4

## Контекст
Заказчик во втором учебном раунде запросил экспорт, исключенный из исходной версии 1.0.

## Рассмотренные варианты
Перенос в следующий релиз; небезопасная выгрузка всех данных; экспорт только своих данных.

## Решение
GET /exports/progress.csv; только собственные цели и отметки, UTF-8 CSV.

## Последствия
Проверки доступа, корректное экранирование полей и защита от CSV-инъекций; дополнительные затраты и тесты.

## Проверка и связь с требованиями
Решение должно быть проверено соответствующими системными требованиями из [requirements.md](../requirements.md) и тестами на этапе реализации. Это документация проектного решения, не свидетельство готового кода.
