# ADR-002: PostgreSQL, JPA и Flyway

**Статус:** Принято  
**Проект:** FocusFlow, ЛР4

## Контекст
Нужны связанные данные, целостность и атомарность отметок привычек/членства.

## Рассмотренные варианты
Хранение без реляционных ограничений; PostgreSQL с ORM и миграциями.

## Решение
PostgreSQL + Spring Data JPA, миграции Flyway.

## Последствия
FK/UNIQUE и транзакции упрощают контроль согласованности; требуется сопровождение схемы и миграций.

## Проверка и связь с требованиями
Решение должно быть проверено соответствующими системными требованиями из [requirements.md](../requirements.md) и тестами на этапе реализации. Это документация проектного решения, не свидетельство готового кода.
