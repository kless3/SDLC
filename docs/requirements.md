# Системные требования FocusFlow

Статус: проект учебной ЛР4. База: SRS ЛР3, FR-001–FR-014 и нефункциональные требования. CHG-002 — добавлено во втором учебном раунде. Критерии проверки предложены для будущей реализации; они **не обозначают, что тесты уже выполнены**.

## Границы версии 1.0
Включено: регистрация и вход; личные цели и прогресс; привычки; календарные события; заметки; команды, общие цели и события; панель дня. Исключено из исходной версии: платежи, отдельное мобильное приложение, push/e-mail, внешние календари, ИИ, сложная аналитика и экспорт. Экспорт добавлен только после CHG-002.

## Минимальные сценарии приемки
1. Пользователь регистрируется и входит; анонимный доступ к личным объектам запрещен.
2. Один пользователь не может читать, менять или удалять цели и заметки другого.
3. Прогресс цели вне диапазона 0–100 отклоняется.
4. Повторная отметка привычки за день не создаёт дубль.
5. Данные команды недоступны посторонним.
6. CSV не содержит чужих данных, корректно кодирован в UTF-8 и защищён от формул таблиц.
